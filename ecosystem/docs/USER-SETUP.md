# Joining Scripture Graph (family member)

Time: about 3 minutes. You need: the invite code from Jace, and (on a phone)
the Obsidian app.

## 1. Get the vault

- **Phone:** install *Obsidian* from the App Store → sign in to Obsidian
  Sync (family account) → connect the **Scripture Graph** remote vault →
  let it finish syncing.
- **Computer:** install Obsidian → open the synced vault the same way.

## 2. Say yes to the plugin

If Obsidian asks about community plugins, enable them. Make sure
**Scripture Graph** is toggled on (Settings → Community plugins).

## 3. Join

A welcome window appears (or: Settings → Scripture Graph → *Join…*):

1. Your name (what the family sees), e.g. "Mom".
2. Paste the invite code (looks like `XXXX-XXXX-XXXX`).
3. Tap **Join**. That's it — no password, no email, no API keys.

The same code will NOT work twice; each person gets their own. Adding your
second device later: on your signed-in device, Settings → Scripture Graph →
*Link another device* → enter that code on the new device instead.

## 4. (Optional) AI

Tap **Connect AI** if you want the ✨ Ask AI features. It opens your browser
to OpenRouter — create an account, add ~$10 of credit, approve. You pay only
for what you use, from your own balance; there's a monthly safety cap in
settings.

Skip it freely — reading, highlighting, notes, and sharing all work without
AI.

## Using it

- **Read:** open any chapter — or use the command *Open in Scripture Graph
  reader* for the clean reader with study lenses (📖 Doctrine, 🏺 History,
  🔬 Evidence, …).
- **Highlight / note:** select verse text → long-press (phone) or
  right-click → pick a color → pick who sees it. 🔐 *Only me* is the
  default; 👥 shares with the family group; 🔒 stays on this device only.
- **See each other:** verses others shared show a small 👥 badge — tap it.
  Toggle the 👥 Family lens in the reader, or scopes in settings.
- **Your notes live in `Library/`** — your folder. The engine's `AI Library/`
  is read-only reference; you can't break it.
- **Export everything** anytime: Settings → Scripture Graph → *Export my
  data* → files appear in `Library/Exports/`.
