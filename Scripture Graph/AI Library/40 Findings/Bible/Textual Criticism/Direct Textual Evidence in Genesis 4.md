# Direct Textual Evidence in Genesis 4

## Summary
<!-- SG:BEGIN summary -->
The chapter explicitly supports a protective function for the mark upon Cain: it is set so that anyone finding him will not kill him. The text supplies no description of the mark's appearance and does not state that it is inherited by Cain's descendants.

**Does not establish:** The verse does not establish what the mark looked like, whether it was bodily, or whether it identified any later population.

**Alternative explanations:**
- The mark could have had additional functions not described in this chapter.
- Later interpretive traditions may assign an appearance or hereditary meaning, but those details do not come from Genesis 4.

**Scripture:** [[Genesis 4#^gen-4-15|Genesis 4:15]]
